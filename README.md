# Soul Test

A lightweight personality quiz built with **React** and **Vite**.

## ✨ Features

- Interactive personality questions
- Fast client-side experience
- Responsive UI
- Production builds with Vite

## 🚀 Development

```bash
npm install
npm run dev
```

Build for production:

```bash
npm run build
```

Deploy to GitHub Pages:

```bash
npm run deploy
```

## 📦 Tech Stack

- React
- Vite
- JavaScript
