# Soul Test

Personality quiz app built with React and Vite.

## Local Development

1. Install dependencies:

   ```sh
   npm install
   ```

2. Start the dev server:

   ```sh
   npm run dev
   ```

## Build

Create a production build:

```sh
npm run build
```

## Deploy to GitHub Pages

Build and publish the `dist` folder:

```sh
npm run deploy
```
